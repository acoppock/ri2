# Package index

## Conducting randomization inference

Simulate the randomization distribution of a test statistic under a
sharp null hypothesis.

- [`conduct_ri()`](https://alexandercoppock.com/ri2/reference/conduct_ri.md)
  : Conduct Randomization Inference
- [`ri_ci()`](https://alexandercoppock.com/ri2/reference/ri_ci.md) :
  Compute a randomization inference confidence interval

## Re-exports

[`tidy()`](https://generics.r-lib.org/reference/tidy.html) generic from
generics, re-exported so that a declaration can be built and tidied
without attaching another package.
